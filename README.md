## 📖 About the Project

This repository holds the source of **Boobesh Palanisamy's personal portfolio website** — built to present who he is as an **aspiring UI/UX Designer and React.js Developer**.

> *"I am an aspiring UI/UX Designer and React.js Developer passionate about creating intuitive and responsive web applications. I have gained hands-on experience through projects, practice, and continuous learning. I am eager to apply my skills, grow professionally, and contribute to impactful digital products."*

**Purpose:** A single destination for recruiters, collaborators, and clients to explore his background, education, design work, and development projects.

**Built for:** Hiring managers, tech recruiters, potential freelance clients, and fellow developers/designers.

**Design Philosophy:** A dark, glassmorphism-inspired interface with neon pink-purple-blue gradient accents, card-based layouts, and a playful hand-drawn/brush-style display font for section headers — giving it a bold, creative-studio feel rather than a plain corporate resume look.

**Key Goals:**
- 🎯 Present skills, education, and projects clearly and visually
- 🎯 Blend **UI/UX design** case studies with **working React projects**
- 🎯 Make it effortless for visitors to connect (resume, socials, contact form)

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/boobeshpalanisamy0612/Portfolio.git

# Move into the project directory
cd Portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```
