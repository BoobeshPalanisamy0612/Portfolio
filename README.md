## 📖 About The Project

> *"I am an aspiring UI/UX Designer and React.js Developer passionate about creating intuitive, accessible, and responsive web applications. I bridge the gap between human-centered design and functional code."*

This repository houses the source code for **Boobesh Palanisamy’s Official Portfolio Website**. Built to step away from traditional corporate resume sites, it features a **neon-glow dark mode**, glassmorphism cards, and interactive modal dialogs for displaying technical and visual projects side-by-side.

### 🎯 Primary Objectives
- **Dual Showcase:** Seamlessly blending full React application builds with interactive UI/UX design case studies.
- **Conversion-Driven:** Optimized pathways for recruiters and clients to download my resume, inspect code, or send direct inquiries.
- **Visual Personality:** Utilizing custom hand-drawn display accents and modern dark gradients (`#0D0D0D` → `#EC4899`).

## 🚀 Getting Started

Follow these simple setup steps to run this project locally on your system.

### Prerequisites
* **Node.js** (v16.0.0 or higher recommended)
* **npm** or **yarn** package manager

### Local Environment Setup

1. **Clone the repository**
   ```bash
   git clone [https://github.com/boobeshpalanisamy0612/Portfolio.git](https://github.com/boobeshpalanisamy0612/Portfolio.git)
Navigate into the project directory

Bash
cd Portfolio
Install dependencies

Bash
npm install
Launch local development server

Bash
npm run dev
Navigate to http://localhost:5173 in your browser.

Build for production

Bash
npm run build
