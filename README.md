## 📖 About The Project

<img align="right" width="300" src="https://user-images.githubusercontent.com/74038190/216656226-a0a5cca6-c02e-4c6e-9c1c-33f6bd60cff1.gif" alt="coding gif"/>

> *"I am an aspiring UI/UX Designer and React.js Developer passionate about creating intuitive, accessible, and responsive web applications — bridging the gap between human-centered design and functional code."*

This repository houses the source code for **Boobesh Palanisamy's Official Portfolio Website** — a deliberate step away from the typical corporate resume site. It's built around a **neon-glow dark mode**, glassmorphism cards, and interactive modal dialogs that let technical builds and visual design work live side by side.

<br/>

| 🎯 Objective | What it means |
|---|---|
| 🔀 **Dual Showcase** | Blends full React application builds with interactive UI/UX design case studies in one place |
| 📈 **Conversion-Driven** | Clear, optimized paths for recruiters and clients to grab my resume, browse code, or reach out directly |
| 🌈 **Visual Personality** | Hand-drawn accents layered over a dark gradient canvas, `#0D0D0D → #EC4899` |
| ⚙️ **Performance First** | Lazy-loaded assets, optimized SVGs, and a Vite-powered build for a fast first paint |

## 🚀 Getting Started

<table width="100%">
<tr>
<td width="50%" valign="top">

### ✅ Prerequisites
- **Node.js** `v16.0.0` or higher
- **npm** or **yarn** package manager
- A modern browser (Chrome, Edge, Firefox)

</td>
<td width="50%" valign="top">

### 📦 What You'll Get
- Local dev server with hot reload
- Full source access to every component
- Production-ready build output

</td>
</tr>
</table>

**1. Clone the repository**
```bash
git clone https://github.com/boobeshpalanisamy0612/Portfolio.git
```

**2. Navigate into the project directory**
```bash
cd Portfolio
```

**3. Install dependencies**
```bash
npm install
```

**4. Launch the local development server**
```bash
npm run dev
```
> Open **http://localhost:5173** in your browser.

**5. Build for production**
```bash
npm run build
```
